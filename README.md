# TemporalTodoJS

Repositorio de ejercicios y prácticas de desarrollo web con **HTML, CSS y JavaScript**, acompañado de ejemplos puntuales en **PHP**. Reúne material sobre funciones, arrays, objetos, DOM y eventos, además de prácticas de juegos y formularios.

## Cómo orientarse

El repositorio está organizado en varias colecciones. **El esquema de ejercicios de este README** permite localizar las veinte prácticas numeradas de clase; después encontrarás accesos a otros ejemplos.

| Carpeta | Contenido |
| --- | --- |
| [Cliente](Cliente/) | Ejemplos por temas y unidades, prácticas y ejercicios de clase. |
| [Ejercicios de clase 2025–26](Cliente/class_2025_26__Ejercicios_programando_en_clase/) | Colección numerada del 01 al 20, con archivos de código e imágenes asociadas. |
| [JS-Diego_Herrea_Ayuso](JS-Diego_Herrea_Ayuso/) | Prácticas como Atrapa al topo, Memory, Bingo, puzle, formularios y tareas. |
| [OneDrive_1_5-11-2026](OneDrive_1_5-11-2026/) | Otra colección de ejercicios, ejemplos de estructuras de datos y archivos PHP de Ajax. |
| [Clinente_Examen1_Diego_Herrera_Ayuso](Clinente_Examen1_Diego_Herrera_Ayuso/) | Archivos del ejercicio `aciertoPuntoCon`. |

Algunos nombres de ejercicios se repiten entre colecciones. Conviene mantener cada carpeta con sus propios recursos y revisar las diferencias antes de intercambiar archivos.

## Consultar y probar una práctica

1. Localiza el ejercicio mediante el esquema o las carpetas temáticas.
2. Revisa su archivo `.html` y las referencias a scripts, estilos y recursos.
3. Para una primera comprobación de los ejemplos de cliente, abre el HTML en un navegador, conservando la estructura de carpetas.
4. Consulta la consola del navegador si aparecen errores.

Algunas entradas concretas:

- [Hola mundo](Cliente/UT00/HolaMundo.html).
- [Hundir barcos](Cliente/class_2025_26__Ejercicios_programando_en_clase/Class_05_Hundir_barcos/index.html).
- [Memory](JS-Diego_Herrea_Ayuso/Memory/Memory/Memory.html).
- [Puzle](JS-Diego_Herrea_Ayuso/puzle/puzle/puzle.html).
- [Formulario de alta](JS-Diego_Herrea_Ayuso/formulario_alta/formulario_alta/formulario_alta.html).

La apertura directa del HTML no garantiza el funcionamiento de todas las prácticas. Los archivos PHP necesitan un entorno que los interprete; sus requisitos y configuración están pendientes de documentar.

## Organización técnica

Las tecnologías se distribuyen en archivos `.html`, `.css`, `.js` y, en algunos ejemplos, `.php`. Hay carpetas de recursos como `img/` e `imagenes/`, y la práctica de secuencias incluye un archivo de audio.

Los nombres, mayúsculas, espacios y niveles de anidación varían entre ejercicios. Al revisar o mover una práctica, comprueba las rutas exactas de sus dependencias y conserva sus recursos asociados.
